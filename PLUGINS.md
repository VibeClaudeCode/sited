# Плагины tontoho Mode (JavaScript)

Плагины — это обычные файлы `.js`. Они работают внутри приложения на встроенном движке iOS JavaScriptCore.

**Где управлять:** Настройки → tontoho Mode → Плагины. Плагин можно добавить четырьмя способами:
- из файла (через «Файлы»);
- из буфера обмена (скопируй код целиком);
- по ссылке (прямая ссылка на `.js`, например raw.githubusercontent.com);
- кнопкой «Установить примеры».

У каждого плагина есть переключатель вкл/выкл, лог и кнопка удаления.

> Ставь только те плагины, которым доверяешь. Плагин видит текст сообщений, которые ты отправляешь, и сообщений, к которым применяешь его действие из меню. Ещё он может обращаться к интернету.

## Шапка плагина

Это необязательные комментарии в самом начале файла:

```js
// @id my-plugin            уникальный id; если установить плагин с тем же id ещё раз, он обновится
// @name My Plugin
// @version 1.0
// @author Me
// @description Что делает плагин
```

## API

Всё доступно через глобальный объект `tg`.

| Функция | Что делает |
|---|---|
| `tg.onOutgoingMessage(fn)` | `fn(text, chat)` вызывается для каждого исходящего текста (и подписи к медиа). Вернёшь строку — отправится она. Вернёшь `null` или `false` — сообщение не отправится. Ничего не вернёшь — уйдёт как есть. Можно вернуть объект с форматированием — см. «Форматирование» ниже. |
| `tg.addCommand(name, fn)` | Если сообщение начинается с `.name`, вызывается `fn(args, chat)`, где `args` — текст после команды. Возвращаемое значение работает так же, как выше. |
| `tg.addMessageAction(title, fn)` | Добавляет пункт в меню сообщения (долгое нажатие). Вызывается `fn(message)`. Если вернуть строку, она покажется в окне с кнопкой «Copy». |
| `tg.alert(text, title?)` | Показать окно с текстом. |
| `tg.copy(text)` | Скопировать в буфер обмена. |
| `tg.openUrl(url)` | Открыть ссылку. |
| `tg.httpGet(url, cb)` | GET-запрос; `cb(error, body)`, где `error` равен `null` при успехе. |
| `tg.storage.get(key)` / `set(key, value)` / `remove(key)` | Хранилище строк, своё у каждого плагина. Сохраняется между запусками. |
| `tg.log(...)`, `console.log(...)` | Запись в лог плагина (Плагины → Показать лог). |
| `tg.sendMessage(chatId, text[, cb])` | Отправить сообщение в чат. `cb(error)` — `error` равен `null` при успехе. |
| `tg.messages(chatId, limit, cb)` | Последние сообщения чата (до 100). `cb(error, list)`, где `list` — массив `message` (плюс `fromId`, `fromMe`). |
| `tg.api(method, params, cb)` | Данные Telegram: `"getMe"` (твой профиль), `"getChat"` с `{ chatId }`, `"resolveUsername"` с `{ username }`. `cb(error, result)`, где `result = { id, name, type, username }`. |
| `tg.httpPost(url, body, cb)` | POST-запрос; `body` — строка или объект (отправится как JSON). `cb(error, body)`. |
| `setTimeout(fn, ms)` / `setInterval(fn, ms)` / `clearTimeout(id)` / `clearInterval(id)` | Таймеры (работают, пока приложение открыто). |
| `tg.version` | Версия API (`"1.2"`). |

## Форматирование

Обработчик `onOutgoingMessage` или команда могут вернуть объект `{ text, entities }` вместо строки:

```js
// всё сообщение жирным
tg.onOutgoingMessage(function (text) {
  return tg.formatAll(text, "bold");
});

// своя разметка: первое слово курсивом
tg.onOutgoingMessage(function (text) {
  var first = text.split(" ")[0];
  return { text: text, entities: [tg.entity("italic", 0, first.length)] };
});
```

- `tg.formatAll(text, type[, url])` — отформатировать весь текст.
- `tg.entity(type, offset, length[, url])` — один диапазон. `offset` и `length` считаются как индексы строки в JavaScript (`text.length`).
- Типы: `bold`, `italic`, `underline`, `strikethrough`, `code`, `pre`, `spoiler`, `quote`, `url` (нужен `url`).
- Если `text` в объекте не меняли, форматирование, которое ты сделал сам в поле ввода, сохраняется и к нему добавляется новое.

Формат объектов:
- `chat = { chatId: "123", botChatId: "-100123" }` — `botChatId` это ID того же чата в формате Bot API (для отправки через своего бота).
- `message = { id, chatId: "123", text, outgoing, date }`, где `date` — unix-время в секундах.

## Пример

```js
// @id hello
// @name Hello
// @version 1.0

// .hi Вася  →  отправит «Привет, Вася! 👋»
tg.addCommand("hi", function (args) {
  return "Привет, " + (args || "друг") + "! 👋";
});

// Подпись в конце каждого сообщения
tg.onOutgoingMessage(function (text) {
  return text + "\n— отправлено с tontoho";
});

// Пункт меню: посчитать слова
tg.addMessageAction("Сколько слов?", function (message) {
  return "Слов: " + message.text.trim().split(/\s+/).length;
});

// Асинхронный запрос: результат показываем через tg.alert
tg.addMessageAction("Мой IP", function () {
  tg.httpGet("https://api.ipify.org", function (error, body) {
    tg.alert(error ? "Ошибка: " + error : body, "IP");
  });
});
```

## Встроенные примеры

| Плагин | Что умеет |
|---|---|
| Text Tools | `.up` `.low` `.rev` `.mock` `.wide`; в меню — «Reverse text» |
| Calculator | `.calc 2+2*3` → отправит `2+2*3 = 8` |
| Keyboard Layout Fixer | `.fix ghbdtn` → `привет`; в меню — «Fix layout» |
| Templates | `.tset имя текст`, `.t имя`, `.tdel имя`, `.tlist` |
| Message Info | в меню — ID, чат, дата, число символов и слов |
| Bold Messages | каждое отправленное сообщение — **жирным** |
| Bot Buttons | инлайн-кнопки через твоего бота: `.bottoken ТОКЕН`, потом `.btn Текст \| Сайт=https://… \| Кнопка` |
| API Demo | `.me` — твой профиль, `.last` — последние 5 сообщений чата; в меню — «Reply 👍» и «Who is it» |

## Инлайн-кнопки

Кнопки под сообщением Telegram разрешает отправлять **только ботам** — с обычного аккаунта сервер их вырезает. Поэтому плагин отправляет такие сообщения через твоего бота (Bot API):

1. Создай бота в @BotFather и скопируй токен.
2. Добавь бота в группу или канал, где нужны кнопки. В личке с человеком бот писать не сможет, пока тот сам не нажмёт Start у бота, — и сообщение придёт в чат человека с ботом, а не в вашу переписку.
3. Установи пример «Bot Buttons», отправь в любой чат `.bottoken ТОКЕН`.
4. В нужном чате: `.btn Привет! | Сайт=https://example.com | Нравится | Не нравится`.

Кнопки со ссылкой просто открывают ссылку. Остальные кнопки присылают нажатие боту — плагин опрашивает бота каждые 3 секунды, пока приложение открыто, и отвечает всплывающим «You pressed: …».

## Ограничения

- `tg.api` — это не прямой доступ к любому методу Telegram API, а набор готовых методов (`getMe`, `getChat`, `resolveUsername`). Новые методы добавляются в приложение и требуют новой сборки.
- `tg.sendMessage` отправляет сообщения от твоего имени — не делай массовые рассылки, Telegram за это ограничивает аккаунт.

- `onOutgoingMessage` и команды работают синхронно. Сетевой ответ (`tg.httpGet`) нельзя подставить в отправляемое сообщение — его можно только показать через `tg.alert` или скопировать.
- Если плагин зависнет в бесконечном цикле, зависнет и приложение. Удали такой плагин.
- Плагины exteraGram (Python, Android) здесь не работают: API другое.
